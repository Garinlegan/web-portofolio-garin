PORTOFOLIO GARIN — VERSI ANIMASI

ISI FOLDER
- index.html : website portofolio responsif dengan animasi CSS, efek reveal saat scroll,
  partikel latar belakang, kartu proyek interaktif, dan navigasi mobile.
- profile.jpg : tempat foto profil kamu (belum disertakan karena kamu belum mengunggah foto).

CARA MELIHAT
1. Ekstrak ZIP.
2. Buka index.html di Chrome/Edge/Firefox.
3. Untuk menambahkan foto, letakkan foto milikmu di folder yang sama dengan index.html,
   lalu beri nama profile.jpg. Foto akan otomatis menggantikan placeholder inisial.

SEBELUM DIPUBLIKASIKAN
1. Ganti emailkamu@example.com dengan email aktif kamu.
2. Ganti link LinkedIn dan GitHub pada bagian kontak dengan URL profilmu.
3. Periksa kembali deskripsi proyek dan keahlian. Hapus skill yang belum nyaman kamu jelaskan.
4. Tambahkan link GitHub/demo pada setiap proyek jika sudah tersedia.
5. Pastikan foto profil yang dipakai memang ingin kamu publikasikan.

PUBLIKASI GRATIS
- GitHub Pages: buat repository, unggah index.html dan profile.jpg, lalu aktifkan Settings > Pages.
- Netlify: unggah folder hasil ekstrak ke halaman deploy manual Netlify.

TEKNOLOGI
HTML, CSS, JavaScript biasa. Tidak membutuhkan build tools, framework, atau instalasi paket.
